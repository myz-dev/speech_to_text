Settings

On: You speak, then the text is typed into the app you are using, by pressing ⌘V for you. This needs the Accessibility permission; the steps appear here when you switch it on.
Off: the text is only put on the clipboard, and you paste it yourself with ⌘V.

Dictate may not paste yet. macOS has to allow it to press ⌘V for you:

  1. Click Open Accessibility settings. If macOS first shows a dialog, choose Open System Settings.
  2. In the list, switch on Dictate.
  3. Click Restart Dictate: macOS applies the permission only after a restart.

Until then, the text is put on the clipboard for you to paste with ⌘V.

Removes hesitations (ähm, uh), fixes punctuation and recognition errors with gemma3:4b in Ollama (ollama.com), on this Mac. It adds about 1–2 s. The cleanup can change meaning, so the raw transcript stays visible below the cleaned text. If Ollama cannot be reached, the raw text is used. Setup, once: 

brew install ollama   # or the app from ollama.com
ollama serve          # unless the Ollama app is running
ollama pull gemma3:4b

The language you dictate in. Only the cleanup needs it: told nothing, the model may translate the text.
